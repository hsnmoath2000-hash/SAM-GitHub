# SAM — مصدر النظام القابل للتطوير

هذا هو مجلد المشروع الذي تُرفع **محتوياته** إلى المستودع. يحتوي على ملفات النظام المفكوكة، وليس نسخة بيانات أو مجلد إصلاحات متفرقة.

أُخذت ملفات التطبيق من سيرفر الاختبار بتاريخ 2026-10-06 بالقراءة فقط، وأضيفت ملفات التثبيت ومخطط قاعدة البيانات من حزمة الإصدار الثالث. لم تُنسخ كلمات مرور السيرفر أو قاعدة البيانات أو المشتركين، ولم تُغيّر خدمات السيرفر أثناء تجهيز هذا المجلد.

## أين أعدّل؟

| المجلد | المحتوى |
|---|---|
| `application/` | المصدر الأساسي: PHP، الخدمات، API، الواجهات، CSS وJavaScript وPWA |
| `application/includes/` | قواعد الأعمال والصلاحيات والمحاسبة والخدمات المشتركة |
| `application/api/v1/` | مدخل API ووثيقة OpenAPI المتاحة؛ ليست دليلًا على اختبار جميع العمليات |
| `application/assets/` | ملفات الواجهات والتصميم |
| `application/services/` | مصدر خدمات واتساب والمراقبة |
| `database/` | مخطط الجداول والتريجرات والتهيئة العامة دون سجلات تشغيلية |
| `installer/` | مصدر معالج التثبيت، الأدوات المساعدة ووحدات systemd |
| `runtime/` | قوالب FreeRADIUS؛ الروابط وصلاحيات الملفات محفوظة في `archive-metadata.json` |
| `config/` | مثال إعدادات الاتصال؛ لا يحتوي إعدادات السيرفر الفعلية |
| `docs/` | عقود API، متابعة الأعمال، مراجعة التحديث وحدود الاختبارات |
| `tools/` | فحص المستودع وبناء حزمة التثبيت دون تنفيذها |

## الإعداد المحلي

يحتاج التطبيق إلى PHP 8.3 وإضافات PDO MySQL وSQLite وGD والمتطلبات المذكورة في المثبت، مع MariaDB. خدمات الاتصال والرسائل تحتاج أيضًا بيئة Linux وخدماتها؛ خادم PHP محلي وحده لا يحاكي RADIUS أو SSTP.

انسخ `config/app-config.example.php` إلى إعداد **خاص خارج المستودع**، ثم اضبط متغير البيئة `UM_CONFIG_FILE` ليشير إليه. المسار الافتراضي للتطبيق هو `/etc/mikrotik-usermanager/app-config.php`. لا تستبدل `application/config.php` بكلمات مرور؛ هو محمّل الإعدادات الخارجية.

استخدم قاعدة بيانات تطوير معزولة. `database/schema.sql` و`database/triggers.sql` أساس تثبيت جديد، ولا يجوز تشغيلهما باعتبارهما ترقية فوق قاعدة مستخدمة. التغييرات اللاحقة في قاعدة البيانات تحتاج ترحيلات منفصلة ومراجعة قبل النشر.

## الفحص والبناء

```sh
python tools/check_repo.py
python tools/check_repo.py --syntax
python tools/build_release.py
```

الفحص الأول يراجع ملفات المشروع وJSON ومسارات الأرشيف ومنع إدخال الأسرار المعروفة والبيانات التشغيلية. خيار `--syntax` يتطلب `php` و`node` على PATH ويضيف فحص صيغة PHP وJavaScript. لا يدّعي أيٌّ منهما اختبار المحاسبة أو اتصال الراوترات.

البناء ينشئ حزمة في `dist/` ويولّد `application.tar.gz` و`runtime.tar.gz` و`SHA256SUMS` من المصدر الحالي. **لا ينفّذ التثبيت ولا يتصل بسيرفر.** مصدر التطبيق الوحيد المعتمد للبناء هو `application/`؛ لا توجد نسخة واجهات قديمة مكررة في المثبت.

مجلد `runtime/` يحتوي الإعدادات التي تضيفها الحزمة فوق حزمة FreeRADIUS المثبتة بواسطة Ubuntu، وليس نسخة كاملة من ملفات الحزمة. تعريف `eap` يأتي من حزمة Ubuntu؛ أما `detail.log` فهو ملف إعدادات وحدة، وليس سجل طلبات فعليًا.

## حالة العمل

السياسة الحالية تفصل سعر التوزيع المسجل في محاسبة الشبكة عن قبض العميل النهائي ودفتر نقطة البيع. تفاصيل التنفيذ والاختبارات السابقة في `docs/SERVER-UPDATE-REVIEW-20261006-AR.md` و`docs/WORK-TRACKER-AR.md`.

بقيت اختبارات فعلية للراوترات v6/v7، وPWA على الهاتف مع HTTPS صالح، وتسليم الرسائل، والتثبيت الكامل للإصدار الثالث على جهاز فارغ. توجد أيضًا فجوات في تغطية API وأعمال مالية متبقية موثقة. وجود الكود أو نجاح فحص الصيغة لا يعني اكتمال هذه الأعمال.

## النشر إلى المستودع

ابدأ بمستودع خاص وارفع محتويات هذا المجلد. لا ترفع المجلد الأب `SAM ERP`؛ فيه نسخ بيانات وأدوات تشغيل خاصة ليست جزءًا من هذا المصدر. لا ترفع إعدادات `/etc/mikrotik-usermanager` أو محتويات `/var/lib/mikrotik-usermanager` أو قاعدة بيانات فعلية.

ملف `.gitignore` يقلل أخطاء الإضافة، لكنه لا يغني عن مراجعة الملفات الجديدة. لا يتضمن هذا المجلد نشرًا تلقائيًا؛ التعديلات تُراجع وتُختبر على بيئة معزولة قبل نشرها إلى سيرفر مستخدم.
