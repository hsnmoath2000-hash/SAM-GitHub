SAM Fresh Web Installer v3 — 2026-10-05
حزمة تأسيس لسيرفر جديد، وليست تحديثًا أو نسخة احتياطية.
يدعم مسار التأسيس Ubuntu 24.04 x86_64. يتطلب root، إنترنت، مساحة كافية، ونطاقًا توجهه إلى عنوان السيرفر.
لا تشغله على السيرفر الحالي أو على سيرفر عليه مشتركون. يمنع التنفيذ عند وجود التطبيق أو قاعدة radius أو إعداد SSTP.
الاستخدام:
tar -xzf SAM-fresh-web-installer-v3-20261005.tar.gz
cd sam-fresh-web-installer
sudo bash minimal-bootstrap.sh --check
sudo bash minimal-bootstrap.sh
افتح https://SERVER-IP:8443، وطابق بصمة الشهادة الظاهرة بالطرفية، ثم أدخل رمز التثبيت.
أدخل النطاق واسم الشبكة وحساب المالك وكلمة مرور جديدة لا تقل عن 12 حرفًا.
واجهة التهيئة تعرض مرحلة التثبيت. السجل الكامل خاص بـ root:
sudo tail -n 100 /var/lib/sam-web-installer/private/install.log
إن توقف التثبيت فلا تحذف علامات المحاولة ولا تعاود التثبيت فوق حالة جزئية. افحص السجل؛ لا توجد استعادة تلقائية كاملة للنظام.
إذا ظهر أن dpkg غير مكتمل، عالج ذلك أولًا على السيرفر الجديد فقط ثم أعد الفحص.
الحزمة تنشئ مخطط قاعدة البيانات والأدوار والحسابات الافتراضية وشبكة واحدة ومالكًا جديدًا؛ لا تنقل مشتركي السيرفر الأصلي.
تثبت Apache/PHP 8.3 وMariaDB وFreeRADIUS وRedis وSSTP وNode 22 وخدمات المهام وواتساب والمراقبة.
تتيح أدوات الخدمات عبر بوابة المالك مع تحقق الصلاحيات وكتالوج ثابت. تثبيت خدمة مفقودة لا يغني عن إعدادها وربطها.
المنافذ: واجهة HTTPS 443 وHTTP 80؛ SSTP 4406؛ RADIUS UDP 1812/1813 حسب حاجتك مع تقييد المصادر.
لا يفتح المثبت جدار الحماية تلقائيًا. تبقى خدمات Node والمراقبة وقاعدة البيانات على loopback.
الشهادة الأولية ذاتية التوقيع وتحتاج استبدالًا بشهادة موثوقة قبل التعرض العام.
بعد نجاح الدخول، أغلق واجهة التهيئة على السيرفر الجديد:
sudo a2dissite sam-setup
sudo apache2ctl configtest
# إذا ظهر Syntax OK:
sudo systemctl reload apache2
sudo rm /etc/sudoers.d/sam-web-installer
ثم امنع منفذ 8443 في جدار الحماية إن كان مفتوحًا.
اختبار القبول: راجع ACCEPTANCE.json. نجح التثبيت الكامل ودخول المالك والتشخيص والرد الفعلي من RADIUS واستقرار الخدمات.
يبقى اختبار راوتر فعلي والكروت وربط واتساب ومزود SMS والعمليات التجارية خارج اختبار التأسيس.
التجربة أجريت على سيرفر اختبار سبق أن ثُبتت فيه الحزم الأساسية؛ أُعيد تأسيس التطبيق وقاعدة البيانات بالكامل بالنسخة النهائية.
لم تُجر تجربة على صورة Ubuntu ثانية مستقلة، فلا تعد الحزمة ضمانًا لكل بيئة.
للنطاق المحلي sam.local.net، وجه DNS المحلي أو hosts إلى عنوان سيرفر الاختبار؛ اسم النطاق وحده لا ينشئ DNS.

الإصدار v3 يضيف مركز إعداد الشبكة، أنماط الكروت والاستيراد وPWA وAPI للتوقيت والواجهة والجرد وكشف الحساب المقسم.
لا يعني كتالوج API اعتماد جميع العمليات المالية. توجد عمليات متبقية موثقة في API-INTEGRATION-AR.md.
لم يُختبر تأسيس v3 بالكامل على سيرفر فارغ جديد؛ اعتمدت تعديلات التطبيق على .97 واختبارات معزولة. نتيجة تأسيس v2 محفوظة للمقارنة فقط.
