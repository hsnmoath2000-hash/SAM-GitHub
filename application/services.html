إدارة الراوترات

ربط وتحكم مركزي بكافة راوترات المايكروتك

اربط جميع راوترات الهوتسبوت وأبراج البث وخطوط PPPoE التابعة لشبكتك في شاشة واحدة، وتحكم بمصادقة وفصل المشتركين لحظياً بدون الحاجة إلى IP ثابت.

  • ✓ ربط مشفر عبر نفق SSTP VPN دون الحاجة لدفع تكاليف Real IP ثابت
  • ✓ طرد وفصل فوري للجلسات وتعديل السرعات لحظياً (CoA) دون ريستارت للراوتر
  • ✓ توليد سكربت ضبط المايكروتك بضغطة زر وتطبيقه في ثوانٍ
  • ✓ كشف فوري لانقطاع أي راوتر أو برج وإرسال تنبيه مباشر لك

إنتاج وطباعة الكروت

توليد وطباعة الكروت باحترافية وتصاميم جاهزة

أنشئ آلاف الكروت لشبكتك بسرعات وسعات وأسعار مختلفة في ثوانٍ معدودة، واطبعها بتصاميم مخصصة تحمل اسم وشعار شبكتك.

  • ✓ توليد آلاف الكروت بأرقام وسيريالات مشفرة ومعقدة لمنع التخمين
  • ✓ مصمم قوالب متكامل يدعم ورق A4 والطابعات الحرارية (80mm) والمحمولة
  • ✓ دعم باقات متعددة: وقت محدد، حصص جيجابايت، سرعات خاصة، وكروت VIP
  • ✓ كروت شحن رقمية وإمكانية الشحن الفوري عبر الباركود (QR Code)

الموزعون ونقاط البيع

إدارة الوكلاء ونقاط البيع ومخازن العهد

وسّع شبكة مبيعاتك عبر إضافة البقالات والمحلات كنقاط بيع، وحدد نسبة خصم كل وكيل مع متابعة دقيقة لمخزون الكروت والمديونيات.

  • ✓ واجهة كاشير سريعة (POS) للبقالات لبيع الكروت وطباعتها أو إرسالها للعميل
  • ✓ سقوف مديونية ذكية توقف البيع تلقائياً عند تجاوز الوكيل للحد الائتماني المسموح
  • ✓ تنظيم الكروت في مخازن وعهد منفصلة لكل موزع لمنع ضياع الكروت
  • ✓ كشوفات حساب تفصيلية للموزعين توضح المسحوبات والمدفوعات والمتبقي بدقة

حساب الأرباح الصافية والصناديق والمصروفات

  • ✓ تقرير الأرباح والخسائر (P&L) يوضح صافي ربح شبكتك يومياً وشهرياً
  • ✓ إدارة الصناديق النقدية، حسابات البنوك، وسندات القبض والصرف الرسمية
  • ✓ تسجيل المصاريف التشغيلية (إيجار مواقع، فواتير إنترنت، كهرباء، رواتب)
  • ✓ مصفوفة توزيع أرباح الشركاء والمستثمرين في الشبكة حسب نسب المساهمة

الواتساب والرد الآلي

أتمتة خدمة العملاء وإرسال الكروت عبر واتساب

اربط رقم واتساب شبكتك بسهولة، ودع المنظومة ترسل بيانات الكروت والفواتير للمشترين وترد على استفسارات الزبائن آلياً طوال 24 ساعة.

  • ✓ إرسال فوري لبيانات الكرت أو الفاتورة إلى واتساب المشترك بمجرد الشراء
  • ✓ روبوت دردشة ذكي (Chatbot) للرد التلقائي على أسعار الباقات وأرقام الدعم
  • ✓ استعادة كلمات المرور وتأكيد الحسابات عبر كود تحقق (OTP) على الواتساب
  • ✓ ربط مباشر وسهل عبر WhatsApp Web بدون الحاجة لاشتراكات مدفوعة معقدة

خدمة المشتركين

بوابة المشتركين وصفحة الهوتسبوت الذكية

امنح مشتركي شبكتك تجربة استخدام عصرية وسلسة من خلال صفحة تسجيل دخول جذابة وبوابة خدمة ذاتية تعرض الرصيد وسرعة الاتصال.

  • ✓ صفحة هوتسبوت متجاوبة مع كافة الهواتف تحمل اسم وشعار شبكتك وعروضك
  • ✓ تطبيق ويب (PWA) للمشترك لمعرفة الرصيد المتبقي، والاستهلاك، ووقت الصلاحية
  • ✓ شحن الرصيد الفوري عبر كاميرا الجوال ومسح باركود الكرت (QR Code)
  • ✓ ميزة تثبيت الجهاز (MAC Lock) لحماية كرت المشترك من السرقة أو التطفل

المراقبة والتحليل

مركز عمليات الشبكة ومراقبة استهلاك البيانات

تابع صحة واستقرار شبكتك لحظة بلحظة، مع رسوم بيانية لحجم حركة البيانات (Bandwidth) وإحصائيات المنافذ الأكثر مبيعاً.

  • ✓ مراقبة حية لجميع المتصلين الآن بالشبكة مع بيانات الـ IP والـ MAC وسرعة الاتصال
  • ✓ رسوم بيانية توضح حركة الرفع والتحميل وساعات الذروة في شبكتك
  • ✓ إحصائيات أكثر الباقات مبيعاً والمواقع الأكثر استهلاكاً لتوجيه التوسعة بذكاء
  • ✓ سجل تدقيق شامل للعمليات يسجل كل عملية بيع أو تعديل بالوقت واسم المستخدم
